# PopClip Extensions

Custom PopClip extensions for macOS.

## Extensions

### Open Multiline URL

Opens URLs that span multiple lines by joining them into a single URL. This is particularly useful when copying URLs from terminal applications where line breaks are inserted.

[View Extension Details](./OpenMultilineURL.popclipext/README.md)

**Installation:** Double-click the `OpenMultilineURL.popclipext` directory to install.

## About PopClip

[PopClip](https://www.popclip.app/) is a macOS utility that appears when you select text, providing quick actions like copy, paste, search, and more. Extensions allow you to add custom actions.

## Development

These extensions are built using PopClip's JavaScript module system. See the [official documentation](https://www.popclip.app/dev/) for more information on creating extensions.
